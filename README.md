## Installation

```bash
pkg update -y
pkg install git python -y

git clone https://github.com/pars1500/cfscanner.git

cd cfscanner
```

## Run Scanner

```bash
python app.py
```

## Output Files

Scanner Results:

```text
/sdcard/Download/good_cf.txt
```

Generated Configs:

```text
/sdcard/Download/generated_configs.txt
```
